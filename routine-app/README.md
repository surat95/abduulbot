# Routine Tracker (prototype)

แอปมือถือสำหรับติดตามกิจวัตรประจำวัน และถ่ายรูปแนบเป็นหลักฐานได้
ตอนนี้เป็นไฟล์ HTML ไฟล์เดียว (`index.html`) ที่เปิดบนมือถือได้ทันที

## หน้าจอ

| แท็บ | ทำอะไรได้ |
|---|---|
| **วันนี้** | แถบ 7 วันด้านบน (จุดเขียว = ทำครบ, จุดส้ม = ทำบางส่วน) วงแหวน % ความสำเร็จ และรายการรูทีนแบ่งตามช่วง เช้า / บ่าย / เย็น / ก่อนนอน กดวงกลมเพื่อติ๊กว่าทำแล้ว กดไอคอนกล้องเพื่อถ่ายรูปแนบ (ถ่ายแล้วจะติ๊กให้อัตโนมัติ) กดรูปเพื่อดูภาพใหญ่ เพิ่มโน้ต ถ่ายใหม่ หรือลบรูป |
| **ประวัติ** | สถิติ (วันติดกันที่ทำได้ ≥80%, ค่าเฉลี่ย 7 วัน, จำนวนวันที่ทำครบ) ปฏิทิน heatmap 5 สัปดาห์ (กดวันไหนก็ย้อนไปดู/แก้ของวันนั้นได้) และแกลเลอรีรูปทั้งหมด |
| **รูทีนของฉัน** | เพิ่ม / แก้ไข / ลบรูทีน ตั้งชื่อ เวลา และเลือกว่ารูทีนไหน "ต้องถ่ายรูป" (จะมีป้ายสีส้มเตือนจนกว่าจะแนบรูป) |

## โครงข้อมูล

```js
routines: [{ id, name, time: "06:30", photo: true }]       // ช่วงเวลาคำนวณจาก time
logs: { "2026-10-31": { [routineId]: { at, photo?, note? } } }
```

- ข้อมูลรูทีนและการติ๊กเก็บใน `localStorage`
- รูปถูกย่อเหลือด้านยาว 1280px (JPEG) แล้วเก็บใน IndexedDB
- ทุกอย่างอยู่ในเครื่องนั้นเครื่องเดียว ยังไม่มี sync ข้ามเครื่อง

## ถ้าจะทำต่อเป็นแอปจริง

1. **Sync ข้ามเครื่อง / สำรองข้อมูล** — เพิ่ม backend (เช่น Supabase/Firebase) เก็บ logs และรูป
2. **แจ้งเตือนตามเวลารูทีน** — ต้องเป็นแอป native หรือ PWA ที่มี push notification
3. **ห่อเป็นแอป iOS/Android** — ใช้ Capacitor ห่อ HTML นี้ หรือเขียนใหม่ด้วย React Native / Expo
   (มี `expo-camera`, `expo-notifications` ให้ใช้)
4. **รูทีนตามวัน** — เช่น ออกกำลังกายเฉพาะ จ/พ/ศ
